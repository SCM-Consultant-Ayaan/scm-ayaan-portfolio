📒 재고수불부 설치 가이드

지금까지 진행 상황에 맞춰 정리했습니다. 1단계는 이미 완료됐고, 2단계부터 이어서 하시면 됩니다.

✓

1. 저장소 스프레드시트 + Apps Script 세팅

완료

재고수불부_저장소 스프레드시트에 스크립트 10개 파일을 붙여넣고 setupAll()을 실행하셨고, 12개 탭이 정상적으로 생성된 것을 확인했습니다 (법인마스터/창고마스터/환율마스터/연동설정 등).

2

[연동설정] 탭에 두 시트 ID 입력

해야 함

저장소 스프레드시트의 [연동설정] 탭을 열고, 값 열이 비어있는 아래 두 항목을 채워주세요.

항목채울 값
PO_SSID발주내역_관리시트 URL의 /d/와 /edit 사이 문자열
SKU_SSIDSKU 매핑 시트([재고대시보드] 메인 SKU CODE Zip) URL의 같은 부분

예: https://docs.google.com/spreadsheets/d/1AbCd...XyZ/edit 라면 굵게 표시된 부분만 복사해서 붙여넣으시면 됩니다. 나머지 PO_COL_*, SKU_COL_* 항목은 이미 기본값이 채워져 있어 그대로 두셔도 됩니다.

3

법인마스터 · 환율마스터 값 확인

확인 필요
  • [법인마스터] 탭: 아이리스브라이트/케이빅스/말러 3개가 들어가 있습니다. 해외법인이 있다면 이 탭에 행을 추가하고 국내외구분을 "해외", 통화코드를 해당 국가 통화로 입력해주세요.
  • [환율마스터] 탭: KRW/USD/TWD/HKD/CNY 예시 환율이 들어가 있습니다. 실제 환율로 갱신해주세요 (KRW환율 = 그 통화 1단위당 원화).
4

관리자 비밀번호 설정

해야 함

스프레드시트 상단 메뉴 재고수불부 → 관리자 비밀번호 설정을 눌러 비밀번호를 정해주세요. 이미 하셨다면 건너뛰어도 됩니다.

5

웹앱으로 배포

해야 함
  1. Apps Script 편집기 우측 상단 배포 → 새 배포
  2. 유형 선택에서 톱니바퀴 아이콘 클릭 → 웹 앱 선택
  3. "실행 계정"은 나, "액세스 권한"은 모든 사용자로 설정 후 배포
  4. 처음 배포 시 권한 승인 화면이 나오면 승인 (Google이 "확인되지 않은 앱" 경고를 띄우면 고급 → 안전하지 않은 페이지로 이동으로 진행하시면 됩니다 — 본인이 만든 스크립트라 안전합니다)
  5. 배포 완료 후 나오는 웹 앱 URL을 복사해두기 (다음 단계에서 필요)
6

Cloudflare Pages에 프론트엔드 올리기

해야 함

방법 A — 파일 직접 업로드 (가장 간단, 처음엔 이걸 추천)

  1. dash.cloudflare.com 접속 후 로그인 (계정 없으면 무료 가입)
  2. 왼쪽 메뉴에서 Workers & Pages 클릭
  3. 우측 Create application (또는 Create) 버튼 클릭
  4. 상단 탭에서 Pages 선택 → Upload assets(직접 업로드) 선택
  5. 프로젝트 이름 입력 (예: inventory-ledger) → Create project
  6. 제가 보내드린 index.html 파일을 업로드 영역에 드래그 앤 드롭 (파일명이 꼭 index.html이어야 하고, 폴더째 올리지 말고 파일 하나만 올리기)
  7. Deploy site 클릭 → 배포가 끝나면 https://inventory-ledger-xxx.pages.dev 같은 주소가 나옴
  8. 그 주소로 접속해서 페이지가 뜨는지 확인

나중에 파일을 수정했을 때 다시 올리는 법

  1. Pages 프로젝트 페이지에서 Deployments 탭 → Create deployment
  2. 새 index.html을 다시 드래그 앤 드롭 → Deploy

방법 B — GitHub 연동 (이미 이 파일이 GitHub 저장소에 올라가 있어서, 나중에 자동배포를 원하시면)

  1. 위 4번 단계에서 "Upload assets" 대신 Connect to Git 선택
  2. scm-ayaan-portfolio 저장소와 claude/multi-entity-warehouse-inventory-ytc11o(또는 병합 후 main) 브랜치 선택
  3. 빌드 설정에서 "Build command"는 비워두고, "Build output directory"를 inventory-ledger/frontend로 지정
  4. 저장하면 그 뒤로는 GitHub에 새로 push할 때마다 자동으로 재배포됨

배포 후:

  1. 배포된 페이지 접속 → 우측 상단 설정 탭 클릭
  2. "Apps Script 웹앱 URL" 칸에 5단계에서 복사한 URL 붙여넣고 저장
  3. 우측 상단 관리자 로그인으로 4단계에서 만든 비밀번호 입력

여기까지 되면 대시보드/거래입력/재고금액검증 화면이 모두 동작합니다.
